# たいやき (Taiyakii) — แอปพลิเคชันเรียนคำศัพท์ภาษาญี่ปุ่นด้วยระบบ SRS (Spaced Repetition)

> **Taiyakii (たいやき)** เป็นเว็บแอปพลิเคชัน Progressive Web App (PWA) สำหรับฝึกฝนและท่องจำคำศัพท์ภาษาญี่ปุ่น ออกแบบด้วยธีมวัฒนธรรมญี่ปุ่นร่วมสมัย ผสานความน่ารักอบอุ่น (Kawaii & Warm Muji Style) ใช้งานง่าย รองรับการทำงานแบบออฟไลน์ 100% พร้อมระบบทบทวนคำศัพท์อัจฉริยะ Spaced Repetition System (SRS)

## 🌟 ภาพรวมของโครงการ (Overview)

แอปพลิเคชัน **Taiyakii** ได้รับการออกแบบขึ้นเพื่อแก้ปัญหาการลืมคำศัพท์ภาษาญี่ปุ่นของผู้เรียน โดยนำหลักการทางจิตวิทยาความจำและอัลกอริทึม **Spaced Repetition System (SM-2 Algorithm)** มาจัดรอบระยะเวลาในการทบทวนคำศัพท์อย่างเป็นระบบ ตัวแอปทำงานบนเว็บเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งไลบรารีภายนอกขนาดใหญ่ และสามารถติดตั้ง (Install) ลงบนหน้าจอหลักของสมาร์ตโฟนหรือแท็บเล็ตในรูปแบบ PWA ได้

## ✨ คุณสมบัติเด่น (Key Features)

- 🎨 **ดีไซน์เอกลักษณ์ Taiyakii & Japanese Pastel Theme**:
  - โทนสีครีม-น้ำตาลอบอุ่น ผสมผสานลายเมฆ ลายต้นสน และภาพประกอบขนมไทยากิ ศาลเจ้าโทริอิ ดารุมะ และสุนัขจิ้งจอก
- 🔄 **ระบบการ์ดคำศัพท์ 3D Interactive (Flashcard)**:
  - พลิกดูคำอ่าน/คำแปลด้วย 3D CSS Transform
  - รองรับการควบคุมด้วยระบบสัมผัส (Touch Gestures: แตะเพื่อพลิก, ปัดซ้ายไปคำถัดไป, ปัดขวาย้อนกลับ)
- 🧠 **ระบบ Spaced Repetition (SRS)**:
  - ประเมินระดับความจำ 4 ระดับ: *ไม่รู้ (Again)*, *ยาก (Hard)*, *จำได้ (Good)*, *ง่าย (Easy)*
  - คำนวณช่วงเวลาการทบทวนซ้ำอัตโนมัติ เก็บข้อมูลลงใน IndexedDB
- 🔊 **ระบบสังเคราะห์เสียงอ่าน (Web Speech API / TTS)**:
  - ฟังการออกเสียงคำศัพท์และประโยคตัวอย่างภาษาญี่ปุ่นแท้
  - ปรับสปีดความเร็วของเสียงอ่านได้ตามต้องการ (0.5x – 1.3x)
- 📊 **แดชบอร์ดสถิติและการติดตามผล (Learning Analytics)**:
  - แสดงจำนวนครั้งที่เรียนในสัปดาห์นี้, เดือนนี้, ปีนี้ และจำนวนวันเรียนต่อเนื่อง (Streak)
  - กราฟแท่งแสดงคำศัพท์ที่สะสมในรอบ 7 วันล่าสุด (Sunday – Saturday) แบบแยกสีเฉพาะวัน
- 🌸 **ระบบจัดการคลังคำศัพท์และตัวกรอง**:
  - สลับการแสดงผลคำศัพท์ได้ทั้ง Kanji, Hiragana และ Katakana
  - บุ๊กมาร์กคำศัพท์ที่ชอบ (Favorites) และบันทึกคำที่ต้องการทบทวนซ้ำ (Review List)
- 📱 **Progressive Web App (PWA) & 100% Offline Capability**:
  - มี Service Worker แคชไฟล์ทั้งหมด ใช้งานได้แม้ไม่มีสัญญาณอินเทอร์เน็ต

## 📱 โครงสร้างหน้าจอตามลำดับการแสดงผล (Screen Flow & UI Hierarchy)

ตามลำดับสถาปัตยกรรม UI ที่ออกแบบไว้ แอปพลิเคชันประกอบด้วย 5 ส่วนหลัก:

### 1. หน้าต้อนรับ (Splash Screen / Welcome View)
- ข้อความอวยพรด้านบน: `良い一日をお過ごしください` (ขอให้มีวันที่ดี)
- ภาพประกอบตรงกลาง: เสาโทริอิ (Torii Gate) พร้อมแก๊งเพื่อนสัตว์ (กระรอก, ลูกเจี๊ยบถือขนมไทยากิ, จิ้งจอก)
- โลโก้หลัก: ป้ายแบรนด์ `たいやき Taiyakii`
- ปุ่มเริ่มต้นเข้าสู่แอปพลิเคชัน

### 2. หน้าหลัก: เรียนคำศัพท์ (Learn View / Flashcard)
- **Top Bar**: โลโก้แบรนด์ด้านซ้าย และปุ่มเมนูตัวกรองทรงกลมสีพาสเทลด้านขวา
- **Flashcard Front (หน้าการ์ด)**:
  - ป้ายบอกระดับคำศัพท์ (Level Badge) ด้านบน
  - ปุ่มรูปลำโพงสำหรับฟังเสียงอ่าน
  - คำศัพท์ภาษาญี่ปุ่นขนาดใหญ่ รองรับ Furigana/Ruby
  - คำอ่าน Romaji
  - ปุ่มคำแนะนำ "แตะการ์ดเพื่อดูคำแปล"
  - ตราประทับดารุมะมงคล (Daruma Stamp)
- **Flashcard Back (หลังการ์ด)**:
  - ความหมายภาษาไทยขนาดใหญ่
  - หมวดหมู่คำศัพท์
  - ประโยคตัวอย่างการใช้งานภาษาญี่ปุ่น พร้อมเสียงอ่านและคำแปลไทย
  - ปุ่มประเมิน SRS 4 ปุ่ม (Again, Hard, Good, Easy)
- **Swipe Hints**: ป้ายแนะนำการปัดหน้าจอ (ปัดซ้าย = ถัดไป / ปัดขวา = ย้อนกลับ)

### 3. หน้าบันทึกคำศัพท์ (Saved View)
- แถบสลับหมวดหมู่: 🌸 รายการโปรด (Favorites) และ 🔖 ทบทวนใหม่ (Marked for Review)
- รายการคำศัพท์ที่บันทึกไว้ พร้อมความหมาย และปุ่มลบรายการ

### 4. หน้าสถิติการเรียนรู้ (Stats View)
- แบนเนอร์หัวข้อสไตล์สีน้ำไล่เฉดเขียว-ชมพู
- **4 การ์ดสถิติหลัก**:
  1. *สัปดาห์นี้* (ตกแต่งด้วยแมวดำปีนขอบ)
  2. *เดือนนี้*
  3. *ปีนี้*
  4. *เรียนรู้ต่อเนื่อง (Streak)* (ตกแต่งด้วยแมวดำนอนพัก)
- **กราฟแท่ง 7 วัน (7-Day Vocabulary Chart)**:
  - กราฟแท่งแสดงปริมาณคำศัพท์สะสมในรอบสัปดาห์
  - มีชื่อวันภาษาอังกฤษและตัวอักษรภาษาญี่ปุ่นกำกับ (Sunday `にちようび` ถึง Saturday `どようび`)

### 5. หน้าตั้งค่า (Settings View)
- ตัวเลือกรูปแบบตัวอักษร: `Kanji`, `Hiragana`, `Katakana`
- แถบเลื่อนปรับความเร็วเสียงอ่าน (TTS Rate) พร้อมปุ่ม "ลองฟังเสียง"
- การตั้งค่าการแจ้งเตือนคำศัพท์ใหม่ประจำวัน พร้อมตัวเลือกความถี่ (ทุกวันเวลานี้, ทุก 3 ชม., ทุก 5 ชม., ทุก 12 ชม.)
- ข้อมูลสรุปจำนวนคำในคลัง และปุ่มรีเซ็ตความคืบหน้า SRS ทั้งหมด (สีแดงพาสเทล)
- **PWA Banner**: ป้ายแบนเนอร์ลายคลื่นญี่ปุ่นสีทองสำหรับกดเพิ่มแอปไปยังหน้าจอหลัก (Add to Home Screen)
- ส่วนประดับท้ายหน้า: สวนดอกไฮเดรนเยียและสุนัขจิ้งจอก

### 6. แถบนำทางด้านล่าง (Bottom Tab Bar)
- 📜 **เรียน (Learn)**: ไอคอนม้วนคัมภีร์ญี่ปุ่น
- 🎴 **บันทึก (Saved)**: ไอคอนการ์ดบันทึก
- 🎏 **สถิติ (Stats)**: ไอคอนธงปลาคาร์ป (Koinobori)
- 🌸 **ตั้งค่า (Settings)**: ไอคอนดอกบ๊วย/ซากุระ

## 🛠️ สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Architecture & Technologies)

- **Frontend Core**: Vanilla HTML5, CSS3 (Modern Flexbox/Grid, CSS Variables, 3D Transforms), Vanilla JavaScript (ES6+ Modules)
- **Data Persistence**: `IndexedDB` เก็บข้อมูลคำศัพท์, ประวัติการทบทวน (Review Logs), สถานะ SRS และการตั้งค่าอย่างปลอดภัยบนเครื่องของผู้ใช้
- **Speech Synthesis**: `window.speechSynthesis` (Web Speech API) สำหรับออกเสียงภาษาญี่ปุ่น (`ja-JP`) โดยไม่ต้องพึ่งพา API ภายนอก
- **PWA Support**: Cache-first Service Worker พร้อมกลไก Stale-While-Revalidate รองรับการทำงานออฟไลน์เต็มรูปแบบ
- **Typography**: 
  - ฟอนต์ภาษาญี่ปุ่น: `Zen Maru Gothic` (ทรงกลม น่ารัก สบายตา)
  - ฟอนต์ภาษาไทย: `Prompt` (สไตล์มินิมอล โมเดิร์น อ่านง่าย)

## 🚀 วิธีติดตั้งและเริ่มใช้งาน (Getting Started)

เนื่องจากแอปพลิเคชันใช้งาน Service Worker และ Web APIs จึงจำเป็นต้องรันผ่าน Web Server (HTTP Local Server หรือ HTTPS):

### วิธีที่ 1: รันด้วย Python Built-in Server
เปิด Terminal / Command Prompt ที่โฟลเดอร์ของโปรเจกต์ แล้วพิมพ์คำสั่ง:
```bash
# สำหรับ Python 3
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

### วิธีที่ 2: รันด้วย VS Code Live Server
1. เปิดโฟลเดอร์โปรเจกต์ใน Visual Studio Code
2. ติดตั้ง Extension **Live Server**
3. คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **"Open with Live Server"**

### วิธีที่ 3: ติดตั้งเป็นแอปบนมือถือ (PWA)
1. เปิดเว็บไซต์ผ่านเบราว์เซอร์บนมือถือ (Chrome บน Android หรือ Safari บน iOS)
2. ไปที่หน้า **ตั้งค่า** แล้วแตะแบนเนอร์ **"เพิ่มไว้ที่หน้าจอหลัก"** (หรือเลือกเมนู *Add to Home Screen* ของเบราว์เซอร์)
3. ไอคอน Taiyakii จะปรากฏบนหน้าจอมือถือ สามารถกดเปิดใช้งานแบบ Full Screen ได้ทันที

## 📚 การขยายคลังคำศัพท์ (Expanding Dataset)

โครงสร้างข้อมูลคำศัพท์ใน `data/words-*.json` ถูกออกแบบตามมาตรฐาน JSON Schema ดังนี้:

```json
{
  "id": "taiyaki-001",
  "kanji": "たい焼き",
  "hiragana": "たいやき",
  "katakana": "タイヤキ",
  "romaji": "taiyaki",
  "meaning": "ขนมไทยากิ (ขนมรูปปลา)",
  "level": "n5",
  "categories": ["food", "daily"],
  "example_jp": "たい焼きを食べます。",
  "example_reading": "たいやきをたべます。",
  "example_th": "ทานขนมไทยากิ"
}
```

- สามารถเพิ่มคำศัพท์ได้อย่างไม่จำกัด โดยเชื่อมต่อกับฐานข้อมูลสาธารณะ เช่น **JMdict Project** หรือเชื่อมต่อกับ REST API / Backend Server ผ่านโมดูล `js/api.js`

## 💡 ข้อควรรู้เกี่ยวกับการแจ้งเตือนและ PWA (PWA & Notifications Note)

1. **การแจ้งเตือนบนเบราว์เซอร์**: หากผู้ใช้ปิดแอปบน iOS Safari โดยสมบูรณ์ ข้อจำกัดของระบบปฏิบัติการอาจทำให้การแจ้งเตือนแบบ Local ถูกระงับชั่วคราว การเปิดใช้งานบน Android หรือการติดตั้งเป็น PWA จะให้ประสิทธิภาพการแจ้งเตือนที่เสถียรที่สุด
2. **การทำงานออฟไลน์**: ในการเปิดใช้งานครั้งแรก จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้ Service Worker ดาวน์โหลดและบันทึกชุดไฟล์ทั้งหมดลงใน Cache หลังจากนั้นจะสามารถเปิดใช้งานแบบออฟไลน์ได้ตลอดเวลา
